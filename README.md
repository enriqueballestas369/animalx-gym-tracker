# Animal X Gym Tracker

Mobile-first 5-day workout tracker inspired by the Animal X training format and adapted for Planet Fitness.

## V1
- Today view with Monday–Friday navigation
- Exercise methods: heavy, reps, 60 sec, unilateral 5-5-5, drop sets, 10/10
- Weight logging
- Three-round checkoffs
- 60-second timer
- Weekly completion view
- Weight history
- Local browser persistence

Built with Next.js and designed for Vercel.
